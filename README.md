# 📊 AI Analytics Portfolio

A comprehensive Data Analytics Portfolio consisting of five integrated analytics projects built using Python, Streamlit, Machine Learning, Forecasting, SQL Analytics, and Interactive Data Visualization.

### Portfolio Modules

- 📈 Sales Analytics
- 🏥 Healthcare Analytics
- 🏏 Sports Analytics
- 💰 Financial Analytics
- 🛒 E-Commerce Analytics

Streamlit Deployment:
https://data-analysis-portfolio.streamlit.app/

GitHub Repository:
https://github.com/Maheshukla/data-analysis-portfolio

---

# 📌 Project Overview

This portfolio demonstrates practical data analytics, business intelligence, machine learning, forecasting, anomaly detection, and interactive dashboard development using real-world datasets.

The platform provides a centralized interface where users can switch between multiple analytics domains through a single application.
